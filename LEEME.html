PROYECTO INTEGRADOR · GUÍA RÁPIDA

Tu simulador está listo para abrir y publicar

Los archivos funcionan juntos. No necesitas saber programar ni instalar aplicaciones adicionales.

1. Ábrelo en tu computadora

  1. Descarga el archivo ZIP y elige Extraer todo o Descomprimir.
  2. Entra en la carpeta extraída.
  3. Haz doble clic en index.html. Se abrirá en tu navegador.
Abrir el simulador →

2. Súbelo a GitHub

No subas solamente el ZIP. GitHub Pages necesita los archivos descomprimidos.

  1. Entra en tu cuenta de GitHub y crea un repositorio público llamado, por ejemplo, simulador-pitot-static.
  2. Abre el repositorio y selecciona Add file → Upload files (o el enlace para subir archivos si está vacío).
  3. Arrastra el contenido de la carpeta extraída: index.html, styles.css, app.js, physics.js y la carpeta assets. Puedes subir también la guía, README y pruebas.
  4. Antes de guardar, comprueba que index.html aparece directamente en la raíz del repositorio. No lo dejes dentro de otra carpeta.
  5. Pulsa Commit changes para guardar.

3. Activa GitHub Pages

  1. En el repositorio abre Settings → Pages.
  2. En Build and deployment, selecciona Deploy from a branch.
  3. Selecciona la rama main y la carpeta /(root).
  4. Pulsa Save y espera a que finalice la publicación.
  5. GitHub mostrará el enlace de tu página en esa misma pantalla. Ese es el enlace que puedes compartir con tu profesor.

Ver las instrucciones oficiales de GitHub Pages ↗

4. Haz tu primera prueba

Selecciona Sistema normal, cambia velocidad y altitud y observa las agujas. Después activa Toma estática obstruida, configura un ascenso de +500 ft/min y pulsa Iniciar vuelo. El altímetro quedará fijo y el VSI marcará cero, aunque la altitud actual aumente.

Si algo no aparece

  • Falta la aeronave: verifica que existe assets/aircraft.png.
  • La página no tiene diseño: comprueba que styles.css está junto a index.html.
  • Las agujas no se mueven: comprueba que has subido physics.js y app.js.
  • Se ve un error 404: revisa que index.html esté en la raíz y Pages use la rama correcta. Espera unos minutos tras publicar.

La sección Ayuda explica las unidades, las fallas y los límites del modelo educativo. La velocidad introducida es una referencia IAS ideal, no TAS. Consulta README.md para conocer las fórmulas y fuentes.
